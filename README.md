# 葛洪旭 · 个人主页

一个正在探索人机协作的人的个人主页。职业是保险代理人，页面记录人机协作的探索、作品与保险服务。

## 在线访问

https://ghx18243340330-ui.github.io/my-homepage/

## 页面结构

- 首屏：人机协作探索者介绍
- 关于我：探索人机协作的背景与想法
- 职业：独立展示「保险代理人」职业及服务方向
- 作品：已上线作品与预留的作品位置，可持续添加
- 联系我：微信 / 小红书二维码弹窗、邮箱直邮

## 页面特点

- 单页 HTML，无框架、无构建依赖
- 明亮天空蓝 + 暖金配色，动态渐变背景
- 系统衬线字体排版，适配桌面与移动端

## 本地预览

直接打开 `index.html`，或在当前目录启动任意静态文件服务器。

## 项目结构

```
my-homepage/
├── index.html
├── assets/
│   ├── wechat-qr.jpg
│   ├── xiaohongshu-qr-code.png
│   └── work-homepage.jpg
├── .nojekyll
└── README.md
```

新增作品时，在 `index.html` 的作品区复制一份 `.work-card` 结构并更新内容即可。
