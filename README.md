# 葛洪旭 · 个人主页

一名保险代理人的个人主页。以明亮、可信赖的视觉风格呈现个人介绍与联系方式。

## 在线访问

https://ghx18243340330-ui.github.io/my-homepage/

## 页面特点

- 单页 HTML，无框架、无构建依赖
- 明亮天空蓝 + 暖金配色，动态渐变背景
- 系统衬线字体排版，适配桌面与移动端
- 微信 / 小红书二维码弹窗、邮箱直邮

## 本地预览

直接打开 `index.html`，或在当前目录启动任意静态文件服务器。
